# API

API предоставляет доступ к функциям сервиса «Отмазкогенератор»: генерации отмазки
по описанию ситуации, оценке её убедительности и просмотру истории.

## Основные операции

- `POST /excuses` — сгенерировать отмазку;
- `GET /excuses` — получить историю отмазок;
- `GET /excuses/{id}` — получить отмазку по идентификатору;
- `GET /tones` — получить доступные тоны отмазок.

## Пример запроса

```http
POST /api/v1/excuses
Authorization: Bearer <token>
Content-Type: application/json

{
  "situation": "Опоздал на пару на 40 минут",
  "tone": "pitiful"
}
```

Пример ответа (`201 Created`):

```json
{
  "id": 123,
  "situation": "Опоздал на пару на 40 минут",
  "tone": "pitiful",
  "text": "Меня задержал внезапный разрыв маршрутки, и я бежал последние два километра.",
  "score": { "value": 82, "confidence": 0.91 },
  "modelVersion": "excuse-gen-1.2.0",
  "createdAt": "2026-10-24T09:15:00Z"
}
```

## Ошибки

Все ошибки возвращаются в едином формате:

```json
{
  "code": "INVALID_SITUATION",
  "message": "Situation text must be between 5 and 500 characters"
}
```

| HTTP-код | Когда возникает |
|----------|-----------------|
| 400 | Пустой или слишком короткий текст, неизвестный тон, неверные параметры |
| 401 | Нет токена авторизации или он недействителен |
| 404 | Отмазка с указанным `id` не найдена |
| 422 | Модель не смогла обработать текст ситуации |
| 503 | ML-модель временно недоступна |

## Спецификация

Полное описание API находится в файле [openapi.yaml](openapi.yaml).
Чтобы посмотреть его в интерактивном виде, откройте содержимое файла в
