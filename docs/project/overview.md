# Отмазкогенератор

Сервис, который по описанию неловкой ситуации («опоздал на пару», «не сделал лабу»)
генерирует правдоподобную отмазку и оценивает, насколько ей поверят.
Тон отмазки (жалостливый, официальный, мистический) определяет ML-модель
на основе текста ситуации и выбранного пользователем настроения.

Основные пользователи:

- студент (пользователь сервиса);
- администратор (следит за качеством модели и пополняет базу шаблонов).

Основные функции:

- ввод описания ситуации;
- генерация отмазки с выбором тона;
- оценка убедительности отмазки по шкале от 0 до 100;
- просмотр истории сгенерированных отмазок.
